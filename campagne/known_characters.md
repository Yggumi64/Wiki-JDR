# Personnages

## WILBERT et BOB

### Identité
* **Faction :** Les Navigateurs
* **Etats :** Vivant
* **Métier :** Ingénieur
* **Lien :** Allié, Ancien supérieur.

::: info Description
Un ingénieur des Navigateurs et sont fidèle Golem Bob. Vous l'avez rencontré lors de votre mission de reconnaisaance.
:::

### Compétences
#### Wilbert
::: tip Passif - Bob
Au début du combat, invoque @Bob.
Lorsque l'entité fini son tour à coté d'un allié, elle lance un d4.
L'allié gagne le résultat en dégâts sur sa prochaine attaque.
:::

::: warning Actif - Armure vivante
Déplacement 1; <br>
Convertie les PV restants d'un Golem en Armure; <br>
Déplacement 4.
:::

::: warning Actif - Réparation de Golem
Déplacement 3; <br>
Soigne un Golem de 3 point de vie; <br>
Déplacement 1;
:::

::: warning Actif - Tir de pistolet
Déplacement 2; <br>
Dégâts 3, cible 1, porté 4; <br>
Déplacement 1; 
:::

#### Bob
::: warning Actif - Auto-Destruction
Dégats X, zone cercle 2, porté soi-même; <br>
S'inflige X dégats; <br>
X = PV actuel - 1.
:::

::: warning Actif - Coup propulsé
Déplacement 5; <br>
Dégats 4, porté 1, cible 1.
:::

::: warning Actif - Écrasement
Déplacement 2, saut; <br>
Dégats 5, porté 1, cible 1.
:::

## TORNA

### Identité
* **Faction :** Les Cultistes
* **Etats :** Morte
* **Métier :** Chevalier Noir
* **Lien :** Ennemis.

::: info Description
L'une des potentielle héritière d'Asnod, elle avait été envoyé en mission pour capturé Malachiel.
:::

### Compétences
::: tip Passif - Avatar épineux
Chaque actions appliquant des 'Ronces' laisse une 'Épine' à l'emplacement ou elle est lancé.
Lorsqu'un ennemis traverse une Épine, il se voit appliquer 'Ronces'.
Ronces : Lorsqu'une entité se voit  appliquer 'Ronces', elle lance un d4, puis prend autant de dégâts que le résultat.
:::

::: tip Passif - Enchantement Epineux
Lorsque l'entité traverse un ennemis, elle lui applique 'Ronces'.
'Ronces' : Lorsqu'une entité se voit appliquer 'Ronces', elle lance un d4, puis prend autant de dégâts que le résultat.
:::

::: warning Actif - Bélier de Torna
Déplacement 1 (marche); <br>
Déplacement 4 (course), zone (Ligne); <br>
Dégâts 4, porté 2, cible 1.
:::

::: warning Actif - Saut à la perche
Déplacement 1; <br>
Dégâts 5, porté 2, cible 1; <br>
Déplacement (Saut) en symétrie avec la cible.
:::

::: warning Actif - Taillade Pivot
Dégâts 3, porté 3:3, cible 1. <br>
Si la cible est touché : déplacement 8:8, zone demi-cercle 4.
:::
